AI Study Companion for Engineering Exams

About the Project

AI Study Companion for Engineering Exams is a Python-based study assistant designed to help engineering students prepare for examinations.

Features

- Topic study guides
- Revision notes generation
- Practice quizzes
- Study plan creation
- Interactive menu-based interface

Technologies Used

- Python
- Random module

How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the command:

python app.py

Project Goal

To help engineering students organise their exam preparation and practise important concepts.

Future Enhancements

- AI-powered explanations
- Personalised learning plans
- Subject-wise question banks
- Progress tracking
